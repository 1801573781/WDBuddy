# 0007. 图片生成 PPT 模板：视觉铺底 + 可编辑文字槽

- 状态：已采纳
- 日期：2026-10-20
- 相关：ADR-0006（PPTX 结构守恒）、`template.from_image`、`spec-renderer`

## 背景

`template.from_image` 用「参考图 → 视觉模型产 DesignSpec → python-pptx 矢量重建」生成模板。用户以一张 13 行 × 2 列的模板全览拼贴图（`ppt图片模版.jpeg`，500×1266）为输入，得到的两页成品与参考图毫无相似之处。

## 问题定位（三条独立缺陷，缺一不可解释现象）

1. **分辨率塌陷**：整图被压到最长边 1536px 后一次性送模型。拼贴图里每页只剩几十像素高，小字与几何结构在视觉上已不存在，模型只能"编"。
2. **多页几何一次生成**：提示词要求单次输出全部页的槽位坐标。页数一多必被输出上限截断或幻觉填充，退化成泛化版式描述。
3. **表达力天花板**：矢量图元只有矩形/圆/线，无法表达星空、渐变、光晕、照片、发光图标。**这不是提示词能修的**——即便模型完美理解图片，程序化重建也不可能接近原图。

结论：缺陷 1、2 属工程实现问题，缺陷 3 属架构路线问题。只修前两者，成品仍会"像一点点但完全不对"。

## 决策

改为 **视觉铺底（visual mode）+ 可编辑文字槽** 的双层模型：

- 参考图像素铺满每页作为背景（`add_picture` 全页拉伸），承担一切不可重建的视觉；
- 视觉模型只负责**逐页**提取文字槽（位置/字号/颜色/对齐/角色）与该处背景色；
- 渲染时先用背景色遮罩盖住原图像素文字，再叠原生文本框，保证"改字不留重影"；
- 矢量模式（`vector`）保留为显式选项，供纯几何图元场景使用。

配套工程改造：

- **拼贴图拆页**：视觉模型给出每页归一化外接框 → 回**原图**裁净（不在压缩图上裁）；模型失败时用像素留白投影兜底，仍失败则均分网格。
- **逐页单图提取**：每次只看一页，把"多页几何一次生成"降维成"单页几何一次生成"，这是精度的分水岭。
- **槽位角色词表对齐**：渲染提示词的占位词（"在此输入主标题…"）必须被克隆引擎 `guessRole` 识别为 title，否则克隆时标题被当正文塞进小框。

## 后果

- 还原度由像素保证：成品与参考图视觉一致，文字可改、可换字号、可克隆填充；
- 代价是每页携带一张位图（体积上升），且背景图案不可拆解编辑——这是"像"与"全矢量可编辑"之间的取舍，选"像"；
- 不做超分/放大臆造：低分辨率参考图裁出的页仍会偏糊，属输入限制，应在工具输出中如实告知用户。

## 被否决的方案

- **只改提示词、继续矢量重建**：表达力天花板不可绕过，页面上仍是几个圆和方块。
- **整图均分网格切页**：通栏页（封面/结尾横跨两列）会被切歪，必须靠模型框或留白缝检测。
- **在压缩后的预处理图上裁页**：页缝只有几像素，缩放即丢失，实测导致每行判成"通栏一块"并产出横条垃圾页。
